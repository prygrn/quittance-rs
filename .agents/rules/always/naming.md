Use descriptive names for all identifiers.
Choose names that reveal intent.
Do not use single-letter identifier names.
Loop counters may use single-letter names such as i, j, or k.
Do not abbreviate names.
Use consistent terminology for the same concept throughout the codebase.
Name action functions with verbs.
Name value-returning functions with nouns or noun phrases.
Prefix boolean names with is, has, or should.
Name arrays and collections with plural nouns.
